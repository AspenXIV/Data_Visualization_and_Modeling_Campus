# Bike Sharing dataset

Hadi Fanaee-T, [Bike Sharing](https://doi.org/10.24432/C5W894), UCI Machine Learning Repository. Accessed November 15, 2026. UCI lists the dataset under CC BY 4.0. See the [UCI dataset page and download](https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset) for the data and bundled data dictionary.

`bike_sharing_daily.csv` is the original `day.csv` from the archive. One row is one day of Capital Bikeshare rentals and weather in Washington, DC, during 2011-2012. The app uses `dteday` as the date, `cnt` as the total rentals, `temp` as the normalized temperature (multiplied by 41 for degrees Celsius per the daily file README), and `weathersit` as the weather code (1 clear or partly cloudy, 2 mist or cloudy, 3 light rain or snow, 4 severe weather with no days in this file).

Source study: Fanaee-T, H. and Gama, J., [Event labeling combining ensemble detectors and background knowledge](https://doi.org/10.1007/s13748-013-0040-3).
